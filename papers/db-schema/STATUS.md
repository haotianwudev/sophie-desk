# papers.db status

Live snapshot of the local paper-index DB — how fresh it is, what's in it, and what needs
attention. For the table-by-table column reference, see [README.md](README.md) and the
per-table pages it links. Needs the **SQLite Explorer** Obsidian plugin to render.

## How stale is this right now

```sqlite-query
source: /papers/paper-index/papers.db
sql: |
  SELECT value AS "Last rebuilt (UTC)" FROM meta WHERE key = 'built_at'
```

**This number does not update itself for every source change.** The supervisor rebuilds the
DB automatically, but only as a side effect of a *task* file changing (see
[Runbook.md](../../Runbook.md)'s supervisor section) — editing a paper note, the candidates
backlog, or anything under `gdocs/` does **not** trigger a rebuild. If you just edited one of
those, run this before trusting anything below or on `Papers.md`:

```bash
cd /f/workspace/sophie-pipeline/paper-index
python build_index.py
```

## Row counts

```sqlite-query
source: /papers/paper-index/papers.db
sql: |
  SELECT 'papers' AS "Table", count(*) AS "Rows" FROM papers
  UNION ALL SELECT 'candidates', count(*) FROM candidates
  UNION ALL SELECT 'gdocs_index', count(*) FROM gdocs_index
  UNION ALL SELECT 'article_gdoc_matches', count(*) FROM article_gdoc_matches
  UNION ALL SELECT 'tasks', count(*) FROM tasks
  UNION ALL SELECT 'pipeline', count(*) FROM pipeline
```

`gdocs_index`/`article_gdoc_matches` read 0 if built on a machine without `gdocs/` (gitignored
personal data — only ever present on the user's own workstation). `pipeline` reads 0 always,
as of 2026-09-05 — `notes/pipeline/` isn't implemented yet, see [pipeline.md](pipeline.md).

## Needs attention

```sqlite-query
source: /papers/paper-index/papers.db
sql: |
  SELECT id AS "Task", lane AS "Lane", status AS "Status"
  FROM tasks
  WHERE in_done = 0 AND (status = 'blocked' OR status = 'gate' OR COALESCE(stall_flag,'') <> '')
```

```sqlite-query
source: /papers/paper-index/papers.db
sql: |
  SELECT topic AS "Topic", count(*) AS "Unresolved candidates"
  FROM candidates
  WHERE COALESCE(status, '') = ''
  GROUP BY topic
  ORDER BY count(*) DESC
```

```sqlite-query
source: /papers/paper-index/papers.db
sql: |
  SELECT count(*) AS "Papers still abstract-level (no Detailed Summary)"
  FROM papers WHERE has_detailed_summary = 0
```

## Known limitations, as of 2026-09-05

- **Not live.** Every board on this DB (`Desk.md`, `Papers.md`, this page) reflects the last
  rebuild, not the current instant — see "How stale is this right now" above.
- **Auto-rebuild only covers task changes.** A paper/candidates/gdocs edit needs a manual
  rebuild; only `tasks/*.md` changes trigger the supervisor's automatic one.
- **`pipeline` is a schema with no data.** `notes/pipeline/` (supervisor-written pipeline
  health from Neon + Cloud Scheduler) doesn't exist on disk yet — planned, not built.
- **`gdocs_index`/`article_gdoc_matches` are machine-local.** They read 0 rows on any machine
  without the user's own `gdocs/` folder (gitignored, never committed).
- **Dataview is no longer required anywhere in this vault** (migrated 2026-09-05) — safe to
  uninstall if nothing else needs it. `Skills.md` is the one exception that never used this
  DB: it's fully regenerated by `scripts/gen_skills.py`, no query involved.
