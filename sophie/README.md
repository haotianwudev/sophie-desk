# Sophie — the work model

This folder is where the operating model itself lives, in plain English, so it's readable on
its own without opening the [design artifact](https://claude.ai/code/artifact/089d0f72-450d-4547-8204-6953842e7f90)
it was originally pitched in.

- **[work-model.md](work-model.md)** — the whole thing: what the three lanes are, how a task
  moves through the system, who (or what) does the work, where things live, and what gets built
  first.

Everything else in this vault (`Desk.md`, `tasks/`, `Skills.md`) is the model *running*. This
folder is the model *explained*.
